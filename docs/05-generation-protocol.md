# 05 · 生成协议（Generation Protocol）

## 硬规则

1. **仅** Context Pack 内句子可作为「原文依据」。  
2. 输出必须分栏，顺序固定。  
3. Pack 空或 `low_confidence` → 进入拒引模板，不得伪造出处。  
4. 一次回答：1 个主源书箱 + 至多 1 个辅源。  
6. 中英/繁简：依据栏只贴 Pack 底本原文；中文作答；英/繁可加「意译非原文」。细则见 [12-script-language-retrieval.md](12-script-language-retrieval.md)。

## 标准输出模板

```markdown
## 语料说明
- 书箱：…
- 命中：… 条（low_confidence：是/否）

## 事实澄清
- …

## 主矛盾
一句话：…

## 原文依据
1. 《书名》·locus：「原句……」
2. …

## 据文分析
- （严格解释上述引文对当下问题的含义）

## 延伸推论
- （可选；明确写「以下为迁移推论，非原文原话」）

## 方略
- 上策：…
- 中策：…
- 不可做：…

## 七日内最小动作
1. …

## 复盘信号
- 继续：…
- 改策：…
```

## 拒引模板（L0）

```markdown
## 语料说明
当前库未检索到足够稳健的原文依据（或置信不足）。

## 事实澄清
- …

## 主矛盾
- …

## 典据状态
本次**不以典籍原文为论据**。建议补录/指定篇目：…
也可改述问题中的关键实体，便于检索。

## 无典据情况下的工作方略（经验方法，非引文）
- …
- 明确标注：非原文接地结论
```

## 模型隐式知识边界

| 步骤 | 可用隐式知识？ |
|------|----------------|
| 查询改写 | 是（权宜；扩词应可在库中核验，见 [12 §3.6](12-script-language-retrieval.md)） |
| 写「原文依据」 | **否**（只能复制 Pack） |
| 据文分析 | 是，但须紧扣已引句子 |
| 延伸推论 | 是，必须标延伸 |
| 方略 | 是，且过假可执行审判 |

## 与 Verifier 衔接

生成完成后，抽取所有「原文依据」中的引号内容，交 [06-verification.md](06-verification.md) 校验；失败则删除该条或整段降级为拒引。

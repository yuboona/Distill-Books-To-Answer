# 02 · 总架构与数据流

## 管道总图

```text
                 ┌─────────────────────┐
用户人生问题 ──► │ Router 问题→书箱     │
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │ Retriever 混合检索   │
                 │ 关键词+向量+元数据   │
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │ Rerank / 去重 / 配额 │
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │ Context Pack        │
                 │ 仅含命中原文块       │
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │ Generator 受约束生成 │
                 │ 先引文→分析→方略     │
                 └──────────┬──────────┘
                            ▼
                 ┌─────────────────────┐
                 │ Verifier 引用校验    │
                 │ 必须为 chunk 子串    │
                 └──────────┬──────────┘
                      失败则重写/降级
                            ▼
                       对用户输出
```

## 组件职责

| 组件 | 输入 | 输出 | 备注 |
|------|------|------|------|
| Router | 用户问题 | 书箱 ID 列表、查询改写 | 规则为主；模型改写为 Phase A 权宜，后续改为库证扩词 |
| Retriever | 书箱 + 查询 | 候选 chunks | 匹配用折叠键/英扩词；chunk.text 保持底本。见 [12](12-script-language-retrieval.md) |
| Rerank | 候选 | Top-K Pack | 每书上限、总字数上限 |
| Generator | Pack + 问题 + skill 模板 | 草稿答 | 禁止使用 Pack 外句子作「原文」 |
| Verifier | 草稿 + Pack | PASS / 失败列表 | 失败不得直接展示给用户当真引文 |

## 允许的「模型隐式知识」用途

| 允许 | 禁止 |
|------|------|
| 把人生题改写成更好的检索词（权宜；不得抢路由） | 用记忆伪造原句；用改写把选题锁进模型爱用的范畴 |
| 在「延伸推论」栏做现代迁移 | 把延伸写成「书中曰」 |
| 检索失败时提调查问题清单 | 检索失败仍假装引典 |

## 关键产物：Context Pack

JSON 示意：

```json
{
  "query": "...",
  "boxes": ["epistemology", "strategy"],
  "chunks": [
    {
      "id": "shiji-xiangyu-012",
      "book": "史记",
      "locus": "项羽本纪",
      "text": "...",
      "score": 0.82
    }
  ],
  "total_chars": 2400,
  "low_confidence": false
}
```

若 `chunks` 为空或 `low_confidence=true`，生成器进入 **L0 拒引模式**。

## 与 skill 工作流对齐

原文管道解决「据什么」；skill 七步解决「怎么判」：

1. 定事实  
2. 定矛盾  
3. 定约束  
4. **调史镜（改为：调 Context Pack）**  
5. 给方略  
6. 落实践  
7. 设复盘  

详见 [07-skill-integration.md](07-skill-integration.md)。

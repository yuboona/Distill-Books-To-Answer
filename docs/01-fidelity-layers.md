# 01 · 保真层级（Fidelity Layers）

「忠于原文」在工程上必须可分级验收，避免口头承诺无法检验。

| 层级 | 名称 | 含义 | 阶段要求 |
|------|------|------|----------|
| **L0** | 禁脑补 | 无合格检索命中时，不得输出「典籍证明了…」；可做无典据的事实澄清或给出应补读篇目 | Phase A 起必须 |
| **L1** | 有据 | 每条关键判断至少绑定 1 条可定位引文（书 + 篇/卷 + 原句） | Phase A 起必须 |
| **L2** | 可核对 | 引文是某个 chunk 的连续子串（允许标点/空白归一化） | Phase A 起必须 |
| **L3** | 义理分栏 | 输出区分「原文所述」与「延伸推论」；后者不可伪装成原文 | Phase A 起必须 |
| **L4** | 版本学 | 多版本异文、译者说明、底本信息完整 | Phase C 可选 |

## 验收口令

- **L0 测试：** 清空检索结果强制生成 → 应拒引典，而非「司马迁说过…」  
- **L2 测试：** `verify_quotes` 对助手输出跑一遍 → 全部 PASS  
- **L3 测试：** 人工抽查「延伸」段是否误写成「书中记载」

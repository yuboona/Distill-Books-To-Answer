# 09 · 经籍书箱与问题路由

## 书箱定义

| box_id | 名称 | 核心书 | 决策用途 |
|--------|------|--------|----------|
| `history` | 史鉴 | 史记、资治通鉴 | 人物动机、长周期后果、进退 |
| `epistemology` | 认识 | 实践论、矛盾论、毛选方法篇 | 调查、主次矛盾、实践检验 |
| `strategy` | 兵与权 | 孙子兵法、**君主论** | 利害、虚实、权力不对称、时机 |
| `policy_debate` | 制度论辩 | **盐铁论** | 义利、集中与放任、成本由谁负担 |
| `cultivation` | 心性知行 | 传习录、道德经、沉思录 | 知行合一、知止、可控边界 |

## 问题 → 书箱（Router 规则）

按匹配优先级从上到下，取 Top-1 书箱为主，可加 1 个辅箱。

| 信号（问题中的意图） | 主箱 | 辅箱建议 |
|----------------------|------|----------|
| 空谈、焦虑学习、不落地、要调查 | epistemology | cultivation |
| 多线都想抓、分不清重点 | epistemology | — |
| 组织政治、进退、功高、站队 | history | strategy |
| 对抗、谈判、该不该硬刚、造势 | strategy | history |
| 公司资源分配、效率 vs 正当性、抽成/负担 | policy_debate | epistemology |
| 懂而不行、情绪淹没、用力过猛 | cultivation | epistemology |
| 新岗位掌权、同盟、声誉与实力 | strategy | history |

## 《君主论》使用规范

- **适用：** 权力不对称、新主/新角色、同盟、恐惧与爱戴、机遇与实力。  
- **强制：** 方略必须含「不可做」——违法、加害、毁诺成瘾、自毁长期声誉。  
- **禁止：** 把权术分析写成教人作恶的操作手册；不作现实犯罪建议。  
- **配伍：** 常与 history（后果）或 cultivation（知止）同现，避免单极权术叙事。

## 《盐铁论》使用规范

- **适用：** 组织/公共政策式两难——集中效率 vs 程序与负担；官方功利逻辑 vs 教化/休养逻辑。  
- **取法：** 教用户看见**两边理据结构**与各自代价，而非简单站队骂街。  
- **迁移：** 公司平台抽成、部门集权、个人与集体指标冲突等。  
- **配伍：** 常与 epistemology（抓主矛盾）同现。

## 选源上限

- 每个回答：**1 主箱 + ≤1 辅箱**  
- 引用展示：**≤3 条** 原文依据（多则稀释校验与阅读）  
- 禁止「五本书综述式」炫博
